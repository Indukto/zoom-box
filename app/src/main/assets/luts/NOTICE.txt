LUT provenance note
===================

The following `.cube` files were adapted from MIT-licensed film-emulation
reference files provided by the product owner (local comparison clone kept at
third_party/dazz-retro-camera, not shipped) and renamed to avoid
third-party trademarks:

  golden_200.cube       <- cpm35_kodak_gold_warm.cube   (warm color negative)
  street_mono_400.cube  <- bw_trix400.cube              (B&W classic)
  vivid_cool_400.cube   <- fqs_superia400_natural.cube  (daylight color negative)
  ccd_digicam.cube      <- ccd_r.cube                   (early-2000s CCD compact)

The upstream reference is MIT licensed; this notice is retained per that
license. The remaining `.cube` files in this folder are original to this
project (GPL-3.0, like the app).
